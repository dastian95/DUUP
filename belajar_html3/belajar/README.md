# belajar_html2

Belajar html mata pelajarang UI/UX tanggal 15 Oktober 2026

## Cara menjalankan

Letakkan folder ini di `htdocs`, nyalakan Apache, lalu buka `http://localhost/belajar_html2/`.

## Struktur folder

```
belajar_html2/
├─ index.html    halaman utama
├─ style.css     tampilan
├─ README.md     penjelasan projek
├─ .gitignore    berkas yang tak ikut Git
└─ .git/         riwayat Git (otomatis)
```
