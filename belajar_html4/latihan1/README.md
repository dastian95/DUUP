# CSS Praktikum

Praktikum CSS untuk mata kuliah Pemrograman Web.

## 🚀 Instalasi

Tidak diperlukan instalasi khusus. Pastikan Anda memiliki:
- Web browser modern (Chrome, Firefox, Edge, Safari)
- Text editor (VS Code, Sublime Text, Atom, dll.)

## 💻 Cara Menjalankan

1. Buka folder `praktikumcss-main` di text editor Anda
2. Buka file HTML yang ingin diakses (misalnya `latihan1/index.html`)
3. Klik kanan pada file dan pilih "Open with Live Server" (jika menggunakan VS Code) atau buka di browser secara manual
